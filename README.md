# 7 Kingdoms Lab

Laboratorio de aplicaciones de Felipe Garzón. Cada proyecto vive en su propio repositorio.

| Proyecto | Qué es | Repositorio |
|---|---|---|
| **Thorgrim** | Entrenador personal de Warhammer Age of Sigmar: datos de ejércitos, biblioteca de reglas, seguimiento de partidas, calculadora y un coach con IA. | [felipegarzonc/thorgrim](https://github.com/felipegarzonc/thorgrim) |
| **Bombadil** | Asistente de longevidad basado en evidencia: exámenes de laboratorio en una línea de tiempo, hábitos y check-ins semanales. | [felipegarzonc/bombadil](https://github.com/felipegarzonc/bombadil) |
| **Attraction Engine** | Componente React (`tr-attraction-engine.jsx`). | Este repositorio |
